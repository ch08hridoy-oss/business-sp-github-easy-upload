# Business SP Pro Website — Easy GitHub Upload Edition

This edition is designed for GitHub's browser-based **Add file → Upload files** workflow. All images and videos are placed next to `index.html` in the repository root, so no `assets` folders need to be uploaded or recreated.

## Files
- `index.html` — homepage and portfolio
- `style.css` — layout and responsive design
- `script.js` — navigation, filtering, and email enquiry form
- `*.jpg`, `*.png` — profile photo, logo, portfolio samples and video posters
- `*.mp4` — playable video samples

## Upload through github.com (no subfolders)
1. Download and extract the ZIP on your computer.
2. Open the extracted `business-sp-github-easy-upload` folder.
3. Open your GitHub repository. Use **Add file → Upload files**.
4. Select all the files *inside this folder* (Ctrl+A while the folder is open) and drag them into GitHub's upload area. Do not upload the ZIP itself, and do not select an outer folder.
5. Click **Commit changes**. Wait for the upload to finish.
6. Open **Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save**.
7. When Pages shows **Visit site**, open it and test the gallery and videos.

**Important:** `index.html`, `style.css`, `script.js`, every image, every video, and `README.md` must be at the same top level in the repository. This easy-upload version deliberately does not use an `assets/` folder. If you have uploaded the earlier folder-based version, uploading this complete set into the same repository overwrites the page and adds the root-level media files. For a cleaner repository, you can instead create a new repository and upload this set there.
